# Working rules for this project (from the user – always follow)

- **Never start coding before the user has approved the plan.** Write or update the plan
  (`docs/demo-plan.md`, `docs/asset-plan.md`, later `docs/site-plan.md`), send it to the user, and
  wait for explicit approval and feedback.
- **Never start coding before the user has provided the pictures/videos** the plan depends on
  (see the checklist in `docs/asset-plan.md`).
- When in doubt, ask. A plan or question is always better than unapproved code.
